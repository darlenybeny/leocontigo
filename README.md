
# LeoContigo 📚

Plataforma web educativa para fortalecer la comprensión lectora de estudiantes de tercer grado mediante historias interactivas, cuestionarios y seguimiento del aprendizaje.

## Cliente real

Centro de Educación Básica Nueva Honduras, ubicado en el barrio Palermo de Puerto Cortés, Honduras.

Representante institucional: Josselin Pineda, directora del centro educativo.

## Problema

LeoContigo busca reforzar las habilidades de comprensión lectora mediante una herramienta digital complementaria que permita a los estudiantes practicar tanto en la escuela como desde sus hogares.

## Objetivo

Desarrollar una plataforma web educativa que permita realizar actividades de lectura, evaluar la comprensión y facilitar el seguimiento del aprendizaje.

## Funcionalidades previstas

- Cuentas individuales para estudiantes.
- Biblioteca de historias educativas.
- Cuestionarios de comprensión lectora.
- Retroalimentación de respuestas.
- Registro de puntuaciones y progreso.
- Panel docente para consultar resultados por sección.
- Administración básica de usuarios y contenidos.

## Tecnologías propuestas

- HTML5
- CSS3
- TypeScript
- Vite
- Supabase Auth
- PostgreSQL mediante Supabase
- Git y GitHub

## Arquitectura

La aplicación tendrá una interfaz web desarrollada con tecnologías estándar y una capa de acceso a datos para comunicarse con los servicios de autenticación y almacenamiento.

Se aplicarán principios de separación de responsabilidades, código limpio y control de acceso basado en roles.

## Instalación y ejecución

Las instrucciones de instalación y ejecución se documentarán cuando se configure el proyecto con Vite.

## Pruebas automatizadas

Se incorporarán pruebas para validar las funcionalidades principales y un workflow de integración continua en GitHub Actions.

## Estado del proyecto

En desarrollo. Actualmente se trabaja en la estructura inicial y la implementación de la primera funcionalidad de lectura y comprensión.
